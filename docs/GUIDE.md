## 설치

### 필요한 것

| 무엇 | 어디에 써요 | 설치 |
|---|---|---|
| 파이썬 3.9 이상 | 사무실 서버 | 맥은 Xcode 명령어 도구에 들어 있어요(`xcode-select --install`). 또는 python.org |
| `jq` | 화면에서 보낸 말 전달, 팀원 답장 | 맥 `brew install jq`, 리눅스 `sudo apt install jq` |
| Claude Code 데스크톱 앱 (맥) | 층에 앉힐 세션, 말 걸기·회의·결재·세션 만들기 | |
| Xcode 명령어 도구 (맥) | 맥 기본 파이썬, 맥 앱 만들기 (macOS 12 이상) | `xcode-select --install` |

리눅스에서는 예시 팀과 Codex 읽기 전용 층만 돼요. 말 걸기·회의·결재·세션 만들기는 맥의 Claude 데스크톱 앱이 있어야 해요.

다른 패키지는 없어요. 파이썬 표준 라이브러리와 정적 HTML로 파일만 읽고 쓰는 단순한 구조예요. 맥 앱은 이 맥에서 직접 컴파일하는 Swift 파일 하나예요.

### 한 줄 설치

```bash
curl -fsSL https://raw.githubusercontent.com/Min-heee/agencity/main/install.sh | sh
```

- `~/agencity`에 최신 릴리스를 설치하고 바로 켜요.
- 같은 줄을 다시 실행하면 코드만 새로 받아요. 내 팀 정보는 그대로예요.
- 이미 있는 폴더는 에이전시티 설치본일 때만 덮어써요. git으로 받은 폴더나 다른 파일이 든 폴더에는 설치하지 않아요.
- 설치 위치, 받을 버전, 맥 앱 만들기는 `이름=값`으로 고를 수 있어요. [설정 값과 파일](#설정-값과-파일)을 봐요.

### 맥 앱

맥에 Xcode 명령어 도구(`swiftc`)가 있으면, 설치하면서 이 맥에서 앱을 직접 만들어 `~/Applications/Agencity.app`에 둬요. 그다음 브라우저 대신 앱 창으로 열어요. 명령어 도구 없이 python.org 파이썬을 쓰거나 리눅스면 브라우저로 켜요.

- 서명 계정은 필요 없어요. 이 맥에서 만든 앱이라 그대로 열려요. 임시 서명만 해요.
- 처음 만들 때는 1분쯤 걸릴 수 있어요.
- 다음부터는 응용 프로그램 폴더나 Spotlight에서 **Agencity**를 열어요.
- 창을 닫아도 사무실 서버는 켜져 있어요. Dock 아이콘을 누르면 창이 다시 떠요. 끄려면 앱에서 **⌘Q**.
- 나중에 앱으로 쓰려면 `xcode-select --install`로 명령어 도구를 설치한 뒤 이렇게 해요.

  ```bash
  sh ~/agencity/bin/make_mac_app.sh --open
  ```

- 앱에는 설치 폴더 경로가 들어가요. 설치 폴더를 옮겼다면 새 위치에서 앱을 다시 만들어요: `sh <새 폴더>/bin/make_mac_app.sh --open`

### zip으로 받기

1. [Releases](https://github.com/Min-heee/agencity/releases/latest)에서 소스 zip을 받아 풀어요.
2. 맥은 `Agencity.command`를 더블클릭해요. 명령어 도구가 있으면 앱을 만들어 앱으로 열고, 없으면 python.org 파이썬으로 브라우저에서 켜요.
3. 리눅스는 그 폴더에서 `python3 start.py`로 켜요.

처음 한 번은 "확인되지 않은 개발자"라며 막힐 수 있어요. 그럴 땐 둘 중 하나를 해요.

- **시스템 설정 → 개인정보 보호 및 보안** 아래쪽에서 **그래도 열기**를 눌러요. 예전 macOS는 오른쪽 클릭 → **열기**예요.
- 터미널에서 그 폴더로 가서 `python3 start.py`로 켜요.

> **zip 폴더는 처음부터 한 곳(예: `~/agencity`)에 두고 계속 써요.**
>
> 팀 규칙 파일에 그 폴더 경로가 들어가요. 새 zip을 다른 폴더에 풀면 팀 정보가 따라가지 않아요.

### git으로 받기

```bash
git clone https://github.com/Min-heee/agencity.git && cd agencity && python3 start.py
```

- 맥 앱을 쓰려면 그 폴더에서 `sh bin/make_mac_app.sh --open`.
- 새 버전은 `git pull`로 받아요. 한 줄 설치는 git 폴더를 덮어쓰지 않아요.

## 켜고 끄기

| | 켜기 | 끄기 |
|---|---|---|
| 맥 앱 | 응용 프로그램 폴더나 Spotlight에서 **Agencity** | 앱에서 **⌘Q** |
| 브라우저 | 설치 폴더에서 `python3 start.py` | 켠 터미널 창에서 **Ctrl-C** |

- 맥에서 `Agencity.command`를 더블클릭해도 켜져요. 명령어 도구가 있으면 앱으로, 없으면 python.org 파이썬으로 브라우저에서 켜요.
- 주소는 `http://127.0.0.1:8765`예요.
- 8765 포트가 쓰이고 있으면 다음 빈 포트로 켜고 주소를 알려 줘요.
- 이 폴더의 사무실이 이미 켜져 있으면 새로 켜지 않고 그 페이지를 열어요.
- 브라우저를 열지 않으려면 `python3 start.py --no-open`, 다른 포트로 켜려면 `OFFICE_PORT=8766 python3 start.py`.
- 처음 켜면 [처음 설정](#처음-설정) 화면이 떠요. **나중에 하기**를 누르면 예시 팀으로 열려요.

### 예시 팀 기록 지우기

예시 팀은 둘러보기만 해요. 말 걸기·회의·결재는 받지 않고, 예시 결재는 결재함 숫자에 세지 않아요. 예전 판에서 예시 팀에 말을 걸었다면 `examples/teams/demo/`에 기록이 남아 있어요.

- git으로 받았다면:

  ```bash
  git checkout examples/ && git clean -fdx examples/
  ```

- 그 밖에는 설치 폴더에서 아래를 실행한 뒤 설치를 한 번 더 해요.

  ```bash
  rm -rf examples/teams/demo/chat/*.jsonl examples/teams/demo/meetings/*-M-* examples/teams/demo/.out
  ```

## 업데이트

### 화면에서 받기

사무실이 켜져 있으면 하루에 한 번까지 최신 릴리스를 확인해요. 새 버전이 있으면 화면 위에 "새 버전 vX.Y.Z가 있어요"와 버튼이 떠요.

| 버튼 | 하는 일 |
|---|---|
| **업데이트** | 한 번 더 확인하면, 그 버전(태그)에 고정된 `install.sh`로 코드만 새로 받아요. 한 줄 설치와 똑같아요 |
| **건너뛰기** | 그 버전은 다시 알리지 않아요. 바로 뜨는 **다시 알리기**나 설정의 ‘완료’ 단계에서 되돌려요 |
| 무엇이 바뀌었나요 | 릴리스 노트를 열어요 |

업데이트가 끝나면 저절로 이렇게 돼요.

- 팀 정보와 설정은 그대로예요.
- 맥 앱은 새로 만들어 다시 열어요.
- 브라우저로 켰다면 사무실을 끄고 새 버전으로 다시 켠 뒤 페이지를 새로 불러와요.

알아 두면 좋은 것:

- 업데이트는 화면 위에 ‘전달 중’·‘전달 대기’ 숫자가 없을 때(대기 0) 눌러요. 0.5.3까지의 확인 창은 이걸 알려 주지 않아요.
- 설치하다 실패하면 켜져 있던 사무실은 그대로 두고 이유를 보여 줘요. 새 코드는 받았는데 다시 켜지 못했으면, 화면 안내대로 앱을 ⌘Q로 끄고 다시 열거나 `start.py`를 다시 켜요. 자세한 기록은 설치 폴더의 `.update/last.log`예요.
- 예전 판으로 만든 층이 있으면 사무실 화면에 "N개 층 규칙이 예전 판이에요"가 떠요. **모두 맞추기**를 눌러요([규칙 맞추기](#규칙-맞추기)).
- git으로 받은 폴더에는 버튼 대신 "git pull로 받아요"라고만 알려 줘요. `git pull` 한 뒤 화면 위 **다시 켜기**를 눌러요.
- 맥 앱을 찾지 못하거나 설치 폴더에 쓸 수 없으면, 버튼 대신 한 줄 설치를 다시 실행하라고 알려 줘요.
- 확인할 때는 GitHub API나 로그인 없이 `github.com/Min-heee/agencity/releases/latest`가 넘겨 주는 태그 주소만 읽어요. 보내는 건 `agencity/<버전>` User-Agent뿐이에요.

### 터미널로 켠 사무실 끄기

터미널(`python3 start.py`)로 켠 사무실은 업데이트·다시 켜기 뒤 그 창이 아니라 뒤에서 다시 켜져요. 기록은 `.update/server.log`예요.

끄려면 아래 줄을 붙여 넣어요. 다른 폴더면 `d=` 뒤를 그 폴더 경로로 바꿔요. 적어 둔 번호가 그 폴더의 `start.py`일 때만 꺼요.

```bash
d=~/agencity; p=$(cat "$d/.update/server.pid") && ps -p "$p" -o command= | grep -qF "$d/start.py" && kill "$p"
```

### 알림 끄기

설정의 5단계 ‘완료’에 있는 **새 버전 알림 받기**를 꺼요. 끄면 확인하지 않고 위의 알림도 나오지 않아요. 같은 곳의 **지금 확인**을 누를 때만 확인해요.

`setup.json`에는 `"update": {"enabled": false}`로 적혀요.

### 손으로 받기

- **한 줄 설치로 받았다면**: 같은 줄을 다시 실행해요. 맥 앱도 새로 만들어 다시 열어요.
- **git으로 받았다면**: `git pull` 한 뒤 화면 위 **다시 켜기**를 눌러요.
- **zip으로 받았다면**: 처음 쓰던 폴더에 이렇게 받아요.

  ```bash
  curl -fsSL https://raw.githubusercontent.com/Min-heee/agencity/main/install.sh | AGENCITY_DIR=<그 폴더> sh
  ```

어느 방법이든 [내 정보가 담긴 파일](#내-정보가-담긴-파일)은 그대로 둬요.

켜 둔 채로 새 코드가 깔리면 화면 위에 "새 코드가 설치됐어요 · **다시 켜기**"가 떠요. 누르면 받는 것 없이 그 코드로 다시 켜요. 코드에 오류가 있으면 끄지 않고 이유를 보여 줘요. 이 단추가 없는 예전 판은 Ctrl-C(앱은 ⌘Q)로 끄고 다시 켜요. 다른 곳에서 사무실을 다시 켰으면 **새로고침**이 떠요.

## 처음 설정

처음 켜면 설정 화면이 다섯 단계로 떠요. 나중에 사무실 위쪽의 **설정**을 누르면 언제든 다시 열어요.

| 단계 | 하는 일 | 꼭 해야 하나요 |
|---|---|---|
| 1. 로그인 | GitHub 연결 | 도시에 올릴 때만 |
| 2. Claude 연결 | Claude·Codex 세션 목록 불러오기 | 따로 할 일 없어요 |
| 3. 사무실 만들기 | 추천 팀 보고 고치기, 층·팀원·총괄 정하기 | 네 |
| 4. 공개 범위 | 도시에 내 건물 세우기, 층마다 보일 것 고르기 | 아니요 (기본은 비공개) |
| 5. 완료 | 정리해 보고 사무실 열기 | |

고른 것은 설치 폴더에 적어요. 설정은 `setup.json`(GitHub 아이디·공개 범위·첫 메시지 읽기 허락·사용량 gist, 토큰은 없어요), 층은 `org.json`과 `teams/`, 공개 범위는 `public.json`에도 적어요. 모두 내 정보라 다시 설치해도 그대로 둬요.

### 1단계 로그인

GitHub 로그인은 도시에 올릴 때만 필요해요. 사무실은 로그인 없이도 다 돼요(**로그인 없이 쓰기**).

- **GitHub로 로그인**: 화면에 나온 코드를 복사해 `github.com/login/device`에 넣고 승인해요. 받는 권한은 gist 하나예요.
  토큰은 이 맥의 `~/.config/agencity/github-token.json`에만 둬요. 나만 읽을 수 있는 0600 파일이고, 화면이나 응답에는 내지 않아요.
- **gh(GitHub CLI) 로그인 쓰기**: 터미널에서 `gh auth login`을 해 뒀다면 그 계정으로 연결해요. gh의 토큰은 읽거나 따로 저장하지 않아요.
  gh가 설치돼 있을 때만 보여요. gh로 바꾸면 앱이 받아 둔 토큰은 지워요.

**GitHub로 로그인**이 보이지 않으면 [관리자 메모](#관리자-메모-github-기기-코드-로그인)를 봐요.

### 2단계 Claude 연결

Claude도 Codex도 **따로 로그인하지 않아요.** 이 맥에 저장된 세션 목록만 읽어요.

| | 읽는 것 | 어디서 |
|---|---|---|
| Claude Code | 제목, 폴더, 사이드바 그룹, 마지막 활동 | Claude 데스크톱 앱이 저장한 세션 기록 |
| Codex | 제목(`thread_name`), 폴더(`cwd`), 마지막 활동(세션 파일을 고친 시각) | `~/.codex/sessions/`, `~/.codex/session_index.jsonl` |

- 대화 내용은 읽지 않아요. 예외는 둘이에요([읽는 정보](#읽는-정보)).
  - [추천 팀](#추천-팀)에서 **허락**하면 세션마다 첫 메시지 앞부분에서 역할 낱말을 찾아요.
  - **세션 만들기**·**총괄 만들기**로 기다리는 동안(30분까지)은 그사이 새로 만든 Claude 세션의 첫 메시지에서 자리 표시만 찾아요(허락과 상관없어요).
- Codex에서 보관한 세션(`~/.codex/archived_sessions/`)은 빼요. `~/.codex`에는 아무것도 쓰지 않아요. Codex가 없으면 Claude 세션만 보여요.
- GPT 모델로 쓰는 Codex도 같은 Codex 세션이에요. Gemini CLI는 앞으로 지원해요.

Claude 세션은 Claude 앱 사이드바와 같은 모양으로 묶어 보여 줘요.

1. 앱에서 만든 그룹 (이름과 순서 그대로)
2. 나머지 세션은 프로젝트 폴더별로
3. 폴더 없이 만든 세션은 **이 컴퓨터** 한 묶음

그룹은 앱 설정 파일(`claude_desktop_config.json`)에서 사이드바 그룹 항목만 꺼내 읽어요. 읽지 못하면 폴더별로 보여 줘요.

### 3단계 사무실 만들기

#### 추천 팀

3단계 맨 위에는 **추천 팀**이 먼저 떠요. 세션 목록을 보고 층마다 팀을 추천해 줘요. 카드를 보고 고친 뒤 **추천대로 모두 만들기**를 한 번 누르면 층이 다 생겨요.

- **처음 한 번 물어요.** "세션마다 첫 메시지 몇 줄을 이 맥 안에서만 읽어 역할을 더 잘 맞춰요. 저장하거나 AI에 보내지 않아요."
  - **허락**: 제목에 역할 낱말이 없으면 첫 메시지 앞부분(600자)에서 찾아요.
  - **목록 정보만**: 제목·폴더·그룹·마지막 활동만 써요.
  - 고른 것은 `setup.json`의 `readFirstMessages`에 적어요. 설정에서 언제든 바꿔요.
- **묶는 법**: [직접 고르기](#직접-고르기)와 같아요. Claude 앱의 사이드바 그룹이 먼저, 나머지는 프로젝트 폴더별이에요.
  Codex 세션은 프로젝트 폴더(그 폴더나 위 폴더 중 git 저장소 맨 위)가 같은 묶음에 들어가고, 그런 묶음이 없으면 그 폴더로 새 묶음을 만들어요.
- **빼는 것**: 보관한 세션, 이미 층에 앉은 세션, 총괄(지금 총괄과 제목·첫 메시지가 총괄 같은 세션), 30일 넘게 쉰 세션, 이미 층인 묶음, 설치 폴더에서 연 세션.
  - **이 컴퓨터**(폴더 없이 만든 세션)와 홈 폴더에서 연 세션은 추천하지 않아요. 아래 직접 고르기에서 손으로 더해요.
- **역할**: [팀원 자리](#팀원-자리)의 낱말표로 정해요. 제목이 먼저고, 허락했으면 그다음 첫 메시지에서 가장 먼저 나온 낱말이에요. 맞는 말이 없으면 팀원이에요.
  - 자리마다 작은 글씨로 이유가 붙어요. 예: 제목의 '디자인', 첫 메시지의 '테스트'. 이유에는 맞은 낱말과 어디서 찾았는지만 나와요. 첫 메시지 글은 화면에도 나오지 않아요.
  - **팀장**은 팀장 낱말이 있는 Claude 세션이에요. 없으면 팀장 자리를 비워 둬요. 층을 만든 뒤 그 빈자리에서 **세션 만들기**로 채워요.
  - 첫 메시지에서는 팀장 낱말을 팀장·팀 리드·team lead로만 봐요(‘리드 수집’ 같은 말에 걸리지 않게).
  - Codex 세션은 팀장·총괄이 될 수 없어요. [Codex 자리](#codex-자리-읽기-전용)로 앉아요.
- **이미 팀 사무실이 있는 폴더**: 그 팀의 이름·머리글·팀원을 그대로 두고, 새 세션만 뒤에 더해요. 다른 층이나 총괄에 앉은 세션이 있던 자리는 비워 둬요.
- 카드마다 **빼기**(이 층은 만들지 않아요)와 **고치기**(팀원 편집기를 추천대로 채워 열어요)가 있어요.
- 이미 층인 그룹(그룹 세션이 둘 이상 앉은 층도)과, 층 이름과 이름이 같은 사이드바 그룹의 추천은 새로 만들지 않아요(폴더 이름만 같은 다른 프로젝트는 새 층 추천이에요). 카드에 "이미 ‘층 이름’ 층이 있어요"가 뜨고, **팀원 고치기**를 누르면 그 층 편집기에 카드의 세션을 더해 열어요.
- 최근에 쓴 추천부터 20개씩 보여 줘요. 나머지는 **더 보기**로 봐요. **추천대로 모두 만들기**는 보이는 카드만, 한 번에 20개 층까지 만들어요.
- 한 층은 12자리까지라, 그보다 많은 세션은 추천에 넣지 않아요.
- 추천은 낱말표로만 정해요. AI가 고르는 게 아니라 틀릴 수 있으니 카드를 꼭 보고 고쳐요.

#### 직접 고르기

추천 대신 직접 고르려면 추천 팀 아래의 **직접 고르기**를 써요.

- 2단계와 같은 나무 모양으로 보여 줘요. 예: 내가 만든 그룹(정산앱·블로그·취직) → 프로젝트 폴더(RunningGround) → **이 컴퓨터**
- 항목을 펼치면 그 안의 세션이 보여요. 환경별이든 섹션별이든 정리해 둔 그대로 골라요.
- 그룹(또는 폴더) 하나도, 펼쳐서 고른 세션 하나도 **층으로**를 누르면 층(팀) 하나가 돼요.
  - 예: ‘취직’을 고르면 취직 층
  - 예: ‘이 컴퓨터’를 펼쳐 ‘tokencity’ 세션을 고르면 tokencity 층
- 층 이름은 그룹 이름으로, 세션 하나면 세션 제목으로 채워 둬요.
- 팀 id는 영문 소문자로 채워 둬요. 한글 이름이면 `team-1`처럼 채우고, 고칠 수 있어요.
- 이미 팀 사무실이 있는 폴더를 고르면 팀 이름·머리글·팀원을 그대로 불러와요.
- 한 세션은 한 자리, 한 층에만 앉아요. 이미 다른 층에 앉은 세션은 자리에 미리 앉히지 않아요.

#### 팀원 자리

- 줄마다 **[역할 이름] [이름] [세션] [×]** 이 있어요.
- 맨 앞 줄은 늘 **팀장**이에요. 세션은 비워 둬도 되지만 줄은 뺄 수 없어요.
- 세션 하나로 층을 만들면 그 세션이 팀장 줄에 앉아요. 다른 줄로 옮겨도 돼요.
- 그룹으로 층을 만들면 세션 제목을 보고 역할을 짐작해 미리 넣어요. [추천 팀](#추천-팀)도 같은 낱말표를 써요.

| 세션 제목(또는 허락한 첫 메시지)에 이런 말이 있으면 (일부) | 역할 |
|---|---|
| 팀장, 리드, lead (첫 메시지에서는 팀장, 팀 리드, team lead만) | 팀장 |
| 개발, 구현, 백엔드, 프론트엔드, dev, code | 개발자 |
| 디자인, 시안, 와이어프레임, 피그마, design, UI, UX | 디자이너 |
| 기획, 요구사항, 로드맵, plan, PM, PRD | 기획 |
| 마케팅, 홍보, 문구, marketing, SEO, SNS | 마케팅 |
| QA, 테스트, 검수, test | QA |
| 데이터, 통계, 지표, data, analytics, SQL | 데이터 |
| 리서치, 시장 조사, 사용자 조사, research | 리서치 |
| 맞는 말이 없으면 | 팀원 |

- 같은 역할이 여럿이면 개발자2처럼 번호를 붙여요. 팀장 같은 세션은 팀장 줄에 앉혀요.
- ‘총괄’·‘코디네이터’·coordinator가 들어간 세션은 자리 대신 총괄 후보가 돼요. 지금 총괄(`org.json`)과 이번에 고른 총괄은 어느 층의 자리에도 앉힐 수 없어요.
- **+ 팀원 추가**로 줄을 더해요. 역할 이름은 마음대로 지어요. 개발자·디자이너·기획·마케팅·QA·데이터·리서치·운영을 추천해 줘요.
- 세션 칸에는 그 층의 세션이 먼저, 그다음 다른 세션들이 보여요. **나중에 연결**을 고르면 빈자리로 둬요. 화면에는 ‘빈자리’로 보여요.
- 한 층에 12자리까지예요.

#### Codex 자리 (읽기 전용)

Codex 세션도 층의 자리에 앉혀요. 지금은 **하는 일만 보는** 자리예요.

- 책상에 **Codex · 읽기 전용**으로 보여요. 상태는 Codex 세션 파일을 고친 시각으로 정해요. 2분 안에 고쳤으면 **일하는 중**, 아니면 **대기**예요.
- 말 걸기·회의·결재·전달은 하지 않아요. 책상의 **말 걸기**는 꺼져 있고 "Codex에는 아직 말을 걸 수 없어요"라고 알려 줘요. Codex에 말 걸기는 앞으로 지원해요.
- 팀장 자리에는 앉힐 수 없어요. 같은 Codex 세션은 한 층에 한 자리만이에요.
- 손으로 앉히려면 만들 층이나 **팀원 고치기**에서 자리의 세션 칸을 열고 **Codex (읽기 전용)** 묶음에서 골라요. 다른 층에 앉은 Codex 세션은 고를 수 없게 보여요. 다시 Claude 세션이나 **나중에 연결**을 고르면 Codex 자리에서 빠져요. 홈 폴더 등에서 열어 추천하지 않은 Codex 세션은 추천 팀 아래 **층 자리에 넣기**를 누르면 그 칸으로 가요.
- `team.json`에는 `{"role": "개발자2", "sessionId": null, "codexId": "<Codex 세션 id>", "tool": "codex"}`처럼 적어요.
- `~/.codex`는 읽기만 하고 아무것도 쓰지 않아요.

#### 역할 이름과 표시 이름

| | 역할 이름 | 표시 이름 (선택) |
|---|---|---|
| 쓰이는 곳 | 대화·상태 파일 이름, 회의·결재의 열쇠 | 화면에 보이는 이름 |
| 길이 | 한글·영문·숫자로 12자까지 | 1~20자 |
| 쓸 수 없는 것 | 빈칸, `/`, `.`, 대표, 총괄 (`_` `·` `-`는 돼요) | 줄바꿈 같은 보이지 않는 글자, 대표, 총괄 |
| 겹치기 | 한 층 안에서 겹치지 않게 | 한 층 안의 다른 이름·역할과 겹치지 않게 |

- 표시 이름을 바꿔도 역할은 그대로예요. 화면에 보이는 이름만 달라져요.
- 표시 이름을 비워 두면 ‘층 이름 역할’로 불러요. 화면에는 역할만 보여요.
- 사무실 책상의 ✎로도 표시 이름을 바로 바꿔요. **Enter**로 저장, **Esc**로 취소해요. 예시 팀은 고칠 수 없어요.

#### 층 순서

- **지금 있는 층**은 추천 팀 아래에 건물처럼 보여요. 맨 아래가 1층이고, ↑를 누르면 한 층 올라가요. 바로 저장돼요.
- 사무실 화면의 층 안내에서 **층 순서 바꾸기**로도 바꿔요. 고른 층과 주소는 그대로예요.
- 새로 만들 층은 **몇 층에 둘까요**에서 지금 있는 층 사이를 고를 수 있어요. 기본은 맨 위(가장 높은 층 위)예요.
- 층 번호가 바뀌면 도시에 올린 내용은 다시 올릴 때까지 ‘예전 내용’으로 보여요.

#### 이미 만든 층 고치기

- **팀원 고치기**로 같은 화면을 다시 열어요. 자리를 더하고, 팀장 말고는 빼고, 세션을 바꿔요.
- 뺀 팀원의 대화·상태 파일(`chat/<역할>.jsonl`, `status/<역할>.json`)은 지우지 않아요. 같은 이름으로 다시 넣으면 이어서 보여요.
- 자리 이름을 바꾸면 그 자리의 대화·상태 파일도 새 이름으로 옮겨요. 예전 대화 파일 이름에는 새 파일로 이어 주는 링크를 남겨요. 그래서 예전 이름으로 오는 답도 새 자리 대화에 붙어요.
- 새 이름의 예전 파일이 이미 있으면 옮기지 않고 알려 줘요.

#### 층 폴더

- 그룹이면 그 세션들이 가장 많이 쓴 프로젝트 폴더예요. 세션 하나면 그 세션의 프로젝트 폴더예요.
- worktree는 원래 프로젝트로 봐요. 앱의 임시 폴더와 없어진 폴더는 빼요.
- 그런 폴더가 없으면 층을 만들 때 `~/agencity-teams/<팀 id>` 폴더를 새로 만들어 써요. ‘이 컴퓨터’ 세션처럼 폴더 없이 만든 세션이 그래요. 폴더는 직접 바꿀 수도 있어요.
- 층 폴더 밖에서 연 세션은 층 폴더의 `CLAUDE.local.md`를 읽지 않아요. 완료 화면에 나오는 절대 경로 한 줄(`@~/agencity-teams/<팀 id>/.office/RULES.md`)을 그 세션 폴더의 `CLAUDE.local.md`에 넣거나, 세션 창에 한 번 보내요.

#### 총괄 고르기

- 총괄(코디네이터) 세션도 이 단계에서 골라요. 하는 일은 `python3 bin/new_team.py`와 같아요.
- 총괄로 쓸 세션이 없으면 **총괄 만들기**를 눌러요. 설치 폴더로 새 세션이 열리고, 작성창에 [총괄 지시](COORDINATOR.md)가 설치 폴더 경로까지 채워져 있어요. **Enter**만 누르면 그 세션이 총괄이 돼요.
- 이미 총괄이 있으면 같은 자리의 **총괄 바꾸기**로 새 세션을 총괄로 열어요.
- 화면에서 보낸 말이 팀에 전해지려면 총괄 세션에서 전달을 켜야 해요. [총괄 세션](#총괄-세션)을 봐요.

### 4단계 공개 범위

#### 도시에 내 건물 세우기

건물은 [도시 명단](https://github.com/Min-heee/token-meter)에 있는 사람마다 서요. 여기서 바로 참가해요(node·gh 없이, 1단계 GitHub 로그인만 있으면 돼요).

1. **내 숫자 세어 보기**: 이 맥의 Claude Code·Codex·Gemini CLI 로그에서 토큰 수를 세요. 올라갈 내용을 그대로 보여 줘요. 이때는 아무것도 나가지 않아요.
2. **gist에 올리기**: 내 GitHub 계정의 공개 gist에 사용량 파일을 올려요. 이미 있으면 그 파일만 고치고(`agencity.json`은 그대로), 숫자가 그대로면 고치지 않아요.
3. **참가 신청 열기 ↗**: GitHub에서 **Submit new issue**를 누르면 봇이 몇 분 안에 명단에 넣어요. 화면은 저절로 바뀌어요.
4. **도시에 건물이 서 있어요**가 뜨면 끝이에요. 숫자는 **숫자 다시 올리기**로 새로 올려요.

- **자동으로 올리기**(기본 꺼짐)를 켜면 사무실을 열어 둔 동안 1시간마다, 숫자가 바뀌었을 때만 명단에 있는 그 gist를 고쳐요(새 gist는 만들지 않아요). 순위표의 ‘오늘’이 그만큼 새로워져요. 올릴 때마다 gist 공개 수정 기록이 늘고, 그 기록으로 언제 일했는지 대강 보일 수 있어요. 예전 판에서 ‘하루 한 번 새로 올리기’로 켜 둔 사람은 껐다 켤 때까지 하루 한 번이에요.
- 이미 참가했다면 바로 4번 화면이 떠요.
- 그만두려면 [탈퇴 이슈](https://github.com/Min-heee/token-meter/issues/new?template=leave.yml&title=leave)를 열고, GitHub의 gist 페이지에서 그 gist를 지워요. 지운 뒤에는 이 상자가 다시 **내 숫자 세어 보기**부터 보여요.

#### 층 공개 범위

층마다 공개 범위를 골라요.

| 공개 범위 | 도시에 나가는 층 정보 |
|---|---|
| 비공개 (기본) | 없어요 |
| 건물만 | 없어요 |
| 층 이름 | 층 이름과 소개 |
| 둘러보기 | 층 이름과 소개, 책상(역할 이름)과 상태 |

- 건물(높이·등급·창문 불빛)은 여기서 고른 것과 상관없이 사용량 숫자로 서요.
- 프로필 소개 한 줄은 층과 상관없이 함께 나가요.
- **저장**은 이 맥에만 적어요. 앱에서 저장하면 업무판 제목과 책상의 지금 하는 일은 늘 꺼져요. 넣고 싶으면 [터미널에서](#내-층-공개하기) 켜요.
- **도시에 올리기**를 누르면 나갈 내용을 한 번 더 보여 줘요. 확인하면 내 사용량 gist에 올려요.
- 그래서 사용량 gist가 있어야 해요. 없으면 위의 [도시에 내 건물 세우기](#도시에-내-건물-세우기)로 먼저 올려요.
- 올린 뒤 모든 층을 비공개나 건물만으로 바꾸고 나라도 고르지 않으면 버튼이 **도시에서 내리기**로 바뀌어요. 공개한 층과 나라를 함께 비운 요약을 올려서 도시에서 내려요(건물은 숫자로 계속 서고 ‘나라 안 고름’ 구역으로 가요). 다만 gist 수정 기록에는 예전 판이 남을 수 있어요.
- ‘아직 도시에 올리지 않았어요’나 ‘도시에는 예전 내용이 올라가 있어요’가 보이면, 저장한 설정이 아직 도시에 반영되지 않은 거예요.
- 확인 상자를 띄운 뒤 다른 창에서 설정을 바꾸면 올리지 않고 알려요. **도시에 올리기**를 다시 눌러 새 내용으로 확인해요.

#### 나라

내 건물이 설 나라 구역을 골라요(선택). 처음에는 ‘정한 적 없음’이에요.

- 나라는 직접 골라요. 시간대로 짐작하지 않아요. 찾기 칸에 나라 이름이나 두 글자 코드(예: KR)를 넣으면 목록이 줄어요.
- 고른 나라는 공개 gist의 `agencity.json`(`profile.country`, 두 글자 코드)에 올라가 누구나 봐요. 도시의 구역·카드·순위표에 아이디와 함께 보여요.
- 시간대는 나라와 따로, 나라를 안 골라도 사용량 파일에 공개돼요.
- **고르지 않음**으로 올리면 나라가 빠져요. **정한 적 없음**이면 층을 올려도 gist에 이미 있는 나라([설치 없이 올리는 명령](#설치-없이-건물만-세우기)으로 정했을 수 있어요)는 그대로 둬요.
- 층을 하나도 공개하지 않아도 나라를 고르면 **도시에 올리기**로 나라가 나가요.
- 바꾼 뒤 도시에 보이기까지 몇 분 걸려요. gist 수정 기록에는 예전 값이 남아요.

### 5단계 완료

고른 것을 정리해 보여 주고 사무실을 열어요. 총괄이 아직 없으면 여기서도 **총괄 만들기**를 보여 줘요.

#### 규칙 줄 넣기

**팀 세션들이 팀 규칙을 읽도록 각 프로젝트 폴더에 CLAUDE.local.md 한 줄 넣기**는 기본으로 켜져 있어요. 이번에 만든 층마다 층 폴더의 `CLAUDE.local.md`에 `@.office/RULES.md` 한 줄을 넣어요.

- 그 줄이 이미 있으면 그대로 둬요. 파일이 없으면 만들고, 있으면 맨 끝에 한 줄만 더해요. 다른 글은 지우거나 순서를 바꾸지 않아요.
- 층 폴더가 git 저장소(또는 그 안)면 `.git/info/exclude`에 `CLAUDE.local.md`를 더해 커밋되지 않게 해요. `info/exclude`에 그 줄이 이미 있으면 그대로 둬요(`.gitignore`로 이미 무시돼도 같은 줄을 더해 둬요. 해가 없어요). git 명령은 쓰지 않아요.
- `CLAUDE.local.md`가 링크이거나, 층 폴더가 설치 폴더(또는 그 위 폴더)면 넣지 않아요. 팀 사무실에 `RULES.md`가 없는 층(이미 있던 사무실)도 넣지 않아요.
- 이번에 만들지 않은 층에는 **규칙 줄 넣기** 버튼으로 넣어요.
- 층 폴더 밖에서 연 세션은 층 폴더의 `CLAUDE.local.md`를 읽지 않아요. 그 세션에는 절대 경로 한 줄([층 폴더](#층-폴더) 참고)을 그 세션 폴더의 `CLAUDE.local.md`에 넣거나, 세션 창에 한 번 보내요.

**새 버전 알림 받기**를 켜고 끄는 곳도, 건너뛴 새 버전 알림을 되돌리는 곳도 여기예요.

#### 사용량 알림

기본은 꺼져 있어요. 켜면 이 맥의 Claude·Codex·Gemini 로그에서 토큰 수를 10분마다 세요(사무실 페이지를 열어 둔 동안). **지금 세기**로 바로 셀 수도 있어요.

- 한도는 **5시간**(최근 5시간), **하루**(오늘 자정부터), **이번 주**(월요일 자정부터)마다 정해요. 세 도구를 합친 작업량이에요. 도시 건물과 같은 셈이라 캐시 읽기는 10분의 1로 세요.
- `1500만`, `1천5백만`, `1억 5천만`, `15M`처럼 써요. `2억5천`처럼 헷갈리는 건 받지 않아요(`2억 5천만`으로). 비우면 그 기간은 한도가 없어요.
- 한도의 80%가 되면 위에 ‘오늘 사용량 82% · 1,230만/1,500만’, 넘으면 ‘오늘 한도를 넘었어요’가 떠요. 여러 기간이 걸리면 가장 급한 것 하나만이에요. ✕로 닫으면 그 기간은 그날 다시 뜨지 않아요(80%에서 닫았어도 넘으면 다시 떠요).
- 켜 두면 층 머리글에 그 층 폴더(와 그 안 폴더)에서 오늘 쓴 양이 ‘오늘 1,234만’으로 보여요. 층 폴더가 겹치면 더 안쪽 층으로 세요. Gemini는 층 폴더에서 바로 연 것만 그 층으로 세요.
- 자정(이번 주는 월요일 자정)이 지나면 어제 숫자는 보이지 않고 바로 다시 세요.
- 끄면 로그를 읽지 않고(세는 중이었으면 멈춰요), 센 기록(`.usage/`)도 지워요.

## 사무실 쓰기

### 화면 구성

- **층 안내**는 맨 위 총괄 아래에 층들이 놓여요. 창이 좁으면 건물처럼 1층이 맨 아래이고, 넓으면 왼쪽부터 1층, 2층… 순서예요. 층을 누르면 그 팀 사무실이 아래에 보여요.
- 층마다 책상, 회의실, 업무판, 활동 기록, 보고서가 있어요. 책상에는 세션 상태와 지금 하는 일이 떠요.
- 맨 위에 **결재함**, 총괄 연결 상태, **도시 보기 →**, **설정**이 있어요.

### 말 걸기

- 책상을 누르면 그 세션과 바로 대화해요. 답은 같은 화면에 올라와요. 층 안내 맨 위의 총괄에게도 똑같이 말을 걸어요.
- 작성창은 **Enter**로 보내고 **Shift+Enter**로 줄을 바꿔요. 총괄·팀원·회의 대화 모두 같아요.
- 한글을 조합하는 중의 Enter는 글자만 확정하고 보내지 않아요.
- 팀장·팀원 작성창의 **일 맡기기**를 켜면 목표·결과물·쓸 도구·범위·완료 기준 네 칸이 나와요. 목표만 꼭 쓰고, Enter로 다음 칸, 마지막 칸에서 Enter로 보내요([팀 규칙 9장](TEAM_RULES.md#9-일-맡기기)). 총괄도 팀장에게 일을 맡길 때 이 네 줄로 써요([총괄 지시](COORDINATOR.md)).
- 결재 메모와 회의 열기 메모는 Enter로 보내지 않아요. 버튼으로 보내요. 회의 열기 메모는 ⌘/Ctrl+Enter로도 보내요.
- 작성창은 대화가 길어져도 서랍 맨 아래에 붙어 있어요.

### 회의

- 회의는 사람(대표)만 열어요. 회의실의 **회의 시작**을 눌러요.
- 팀장 자리가 비어 있으면 **회의 시작** 대신 "팀장 자리를 먼저 채워요"와 **세션 만들기**가 보여요. 회의는 팀장이 진행해요.
- **참석**: 내가 회의실에 들어가 같이 대화해요.
- **위임**: 팀끼리 진행하고, 팀장이 결과를 회의록과 결재로 올려요.
- 중간에 빠지면 남은 안건은 팀이 이어서 해요.
  - 위임 회의가 30분 넘게 조용하면 사이트가 팀장에게 마무리하라고 한 번 알려요(회의마다 한 번).
- **회의 끝**을 누르면 회의실이 바로 비어요. 팀원은 회의 전에 하던 일로 보이고, 팀장이 회의록을 써서 닫아요("회의록 정리 중").
  - 팀장이 오래 정리하지 않으면 회의실의 **정리 끝내기 (내가 닫기)**로 직접 닫아요.
- 참석 회의에서 내 말은 처음엔 팀장에게만 가요. 다른 참석자에게도 보내려면 **받는 사람**에서 골라요.
- 팀장은 스스로 회의를 열지 않아요. 회의가 필요하면 회의 요청 결재를 올리고, 결재함에서 **이 주제로 회의 열기**를 누르면 회의가 열리고 결재도 승인돼요.

### 결재

- 팀장이 올린 결재를 결재함에서 고르면 그 팀장에게 바로 전해져요.
- 그 층에 팀장이 없으면 결정만 남기고 "팀장이 없어서 전하지 못했어요"라고 알려 줘요. 팀장 자리를 채운 뒤 다시 알려 주세요.
- 위험한 일은 결재로 "하기로 정함"까지만 해요. 커밋·배포·결제 같은 실제 실행은 그 세션 창에서 사람이 마지막으로 확인해요.

### 노션 링크 (선택)

- `org.json`의 `notion`에 주소를 넣으면 위쪽에 **노션 회의록·할 일·일정 ↗** 링크가 보여요.
- `org.json`의 층(`teams`)마다 `notion`을 넣으면 그 층 머리에도 노션 링크가 생겨요.

### 공유용 스냅샷

`python3 build.py --snapshot`은 지금 팀 상태를 페이지 안에 담아 공유용 `artifact.html`을 만들어요. **팀 데이터가 그대로 들어가니** 공개하기 전에 꼭 확인해요.

## 세션 만들기와 팀 간 대화

### 세션 만들기

빈자리를 새 Claude Code 세션으로 채워요. 사무실 책상의 **빈자리**, 설정 3단계의 **나중에 연결** 줄, **팀원 고치기**의 빈 줄에 **세션 만들기** 버튼이 있어요.

1. 누르면 Claude 앱에 그 층 폴더로 새 Code 세션이 열리고, 작성창에 첫 메시지가 채워져 있어요.
2. 앱이 그 폴더를 열지 물으면 확인하고, **Enter**만 눌러요.
3. 에이전시티가 몇 초 안에 새 세션을 찾아 그 자리에 앉혀요. 화면에 **자리에 앉혔어요 ✓**가 떠요.

- 층 머리의 **빈자리 모두 만들기**(층 만들기 결과에서는 **팀원 세션 모두 만들기**)는 빈자리를 팀장부터 하나씩 열어요. 한 자리가 앉으면 다음 자리가 저절로 열려요.
- Enter는 자리마다 직접 눌러요. 위쪽 줄의 **건너뛰기**로 넘기고, **멈추기**로 그만둬요.
- Claude 앱은 링크로 연 세션의 id를 알려 주지 않아요. 그래서 첫 메시지에 `[에이전시티 자리 표시: AGC-…]` 한 줄을 넣어 두고, 새 세션의 첫 메시지에서 그 표시를 찾아요.
- 표시가 없는 새 세션(대표가 따로 연 세션일 수 있어요)이나 새 세션이 여럿 보이면, 제목만 보여 주고 고르게 해요.
- **다시 열기**를 눌러도 같은 자리 표시를 써요(30분이 지난 뒤에도 한 시간 안이면). 어느 링크로 연 세션이든 그 자리에 앉아요.
- 30분 안에 앉지 않으면 **다시 열기**로 다시 기다려요. 자리에 앉히면 `team.json`의 그 줄 `sessionId`만 바뀌어요.
- 링크를 만들 때 그 층 `RULES.md`가 예전 판이면 먼저 맞춰요([규칙 맞추기](#규칙-맞추기)와 같아요).
- 새 세션은 첫 메시지대로 팀 규칙(`RULES.md`)을 읽고, 상태를 **대기**로 적고, 되면 Claude 앱 사이드바의 층 이름 그룹으로 자기를 옮기고, 팀장(팀장 자리면 총괄)에게 `[보고] 준비됐어요`를 한 번 보내요.
- 커밋·배포 같은 일은 여전히 그 세션 창에서 대표가 직접 정해요.

### 섹션 맞추기

층 머리글의 **섹션 맞추기**를 누르면, 총괄이 그 층 세션들을 Claude 앱 사이드바의 층 이름 그룹으로 모아요. 총괄 세션이 정해져 있어야 해요.

- 사이드바 그룹은 세션 안의 도구로만 바꿀 수 있어요. 문서로 정해진 도구가 아니라서, 없으면 총괄이 이유를 남기고 건너뛰어요.

### 팀 간 대화

- 다른 층과의 이야기는 **팀장끼리만** 해요. `bin/tell.sh`로 기록을 남긴 뒤 `SendMessage`로 보내요. 머리말은 `[협업·보낸 층→받는 층 #T-… 3/6]`이에요.
- 주제마다 대화 번호(`T-…`)가 생겨요. 새 주제는 `--topic`, 답은 `--re T-…`로 보내요. 둘 다 없으면 24시간 안의 마지막 대화를 이어요.
- 한 대화는 왕복 3번(말 6개, 양쪽 다)까지예요. tell.sh가 세고, 넘으면 보내지 않고 총괄에게 `[보고]`로 올리라고 알려 줘요.
- 왕복을 다 쓴 대화에는 **3번 더 하게 두기**가 생겨요. 그 뒤에 팀장이 더 보내려다 막히면 **멈춤 · 대표 확인 필요**로 떠요.
- 상대 층에 팀장이 없으면 tell.sh가 막고, 총괄에게 `[보고]`로 올리라고 알려 줘요.
- 주고받은 말은 `hq/teams.jsonl`에 남고, 사무실 화면의 **팀 간 대화**에서 대화별로 묶어 봐요.
- 다른 팀의 말은 대표의 승인이 아니에요.

### 규칙 맞추기

`RULES.md`에서 에이전시티가 맞추는 부분은 팀 간 대화와 일 맡기기예요. 부분마다 `<!-- agencity:이름 v판 -->` 표시가 있어요. 예전 판으로 만든 층이 있으면 층 안내 아래에 "N개 층 규칙이 예전 판이에요"가 떠요.

- **모두 맞추기**를 누르면 그 층들의 `RULES.md`에서 없는 부분은 맨 끝에 더하고, 예전 판인 부분은 표시 사이만 새 판으로 바꿔요. 표시 밖의 글은 그대로 두고, 이미 새 판이면 아무것도 하지 않아요.
- 표시 사이에 직접 고쳐 쓴 글은 새 판으로 바뀌어요. 바꾸기 전 파일은 `RULES.md.bak`에 남겨요(세션 만들기가 맞출 때도 같아요). 내 규칙은 표시 밖에 써요.
- 한 층만 맞추려면 층 머리글의 **규칙 맞추기**를 눌러요. 그 층이 예전 판일 때만 보여요.
- 링크인 `RULES.md`, 1MB가 넘는 파일, 표시가 깨진 파일(여는 줄이 둘이거나 닫는 줄이 없어요), 예시 팀은 고치지 않아요.
- 새로 여는 세션은 바로 따라요.
- 지금 켜져 있는 팀장은 `RULES.md`를 다시 읽어야 해요. 맞춘 뒤 층 안내 아래에 뜨는 **팀장 N명에게 보내기**를 누르면 "[규칙] RULES.md를 다시 읽어 주세요"를 팀장마다 보내요.

## 총괄 세션

화면에서 보낸 말은 총괄(코디네이터) 세션 하나가 받아서 각 팀 세션에 전해요. 총괄 세션이 켜져 있어야 전달돼요.

### 켜는 법

가장 쉬운 길은 **총괄 만들기**예요. 설정 3단계의 총괄 고르기 자리에 있고, 진짜 총괄이 없으면 사무실 화면 위에도 알려 줘요.

1. **총괄 만들기**를 누르면 Claude 앱에 설치 폴더로 새 Code 세션이 열리고, 작성창에 [총괄 지시](COORDINATOR.md)가 채워져 있어요. `<에이전시티>` 자리에는 설치 폴더 경로가 이미 들어가 있어요.
2. 앱이 폴더를 열지 물으면 확인하고, **Enter**만 눌러요.
3. 에이전시티가 몇 초 안에 그 세션을 찾아 `org.json`의 `boss.sessionId`로 정해요(고치기 전 내용은 `org.json.bak`). 화면 위에 "총괄 연결됨"이 보이면 돼요.

- 첫 메시지에 자리 표시(`[에이전시티 자리 표시: AGC-…]`)가 있는 세션만 저절로 정해요. 표시가 없는 새 세션은 저절로 고르지 않고, 설치 폴더에서 연 새 세션의 제목만 보여 줘 고르게 해요.
- 다시 열어도 같은 자리 표시를 써요(30분이 지난 뒤에도 한 시간 안이면). 30분 안에 찾지 못하면 다시 눌러요. 이미 총괄이 있으면 설정 3단계의 **총괄 바꾸기**로 새 세션으로 바꿔요. 예전 총괄 창은 더 전하지 않고(0.7.0 전에 켠 감시도), 쌓여 있던 말은 새 총괄이 이어서 전해요. 층마다 `RULES.md`에 적힌 총괄 id도 고쳐요.

손으로 하려면:

1. 총괄로 쓸 Claude Code 데스크톱 세션을 하나 정해요. 설정 3단계에서 고르거나, 그 세션 id(`local_…`)를 `org.json`의 `boss.sessionId`에 넣어요.
2. 그 세션에 [COORDINATOR.md](COORDINATOR.md)의 지시를 한 번 붙여 넣어요. 지시 안의 `<에이전시티>`는 설치 폴더의 전체 경로(예: `/Users/나/agencity`)로 바꿔요.
3. 화면 위에 "총괄 연결됨"이 보이면 돼요. 끊기면 "총괄 연결 끊김"이 떠요.

- 총괄 연결이 끊겨 있으면 보낸 말은 쌓여 있다가 총괄이 돌아오면 전해져요. 컴퓨터를 닫았다 열면(잠자기) 총괄 창의 감시가 멈춰서 자주 그래요.
  - 화면 위 "총괄 연결 끊김" 옆의 **다시 연결**을 눌러요. 다시 켜는 말(감시 명령 한 줄)을 복사하고 총괄 창을 열어요.
  - 총괄 창 입력칸에 붙여 넣고(⌘V) Enter를 누르면 "총괄 연결됨"으로 돌아와요. Claude 앱은 이미 있는 세션의 입력칸을 링크로 채워 주지 않아서 붙여 넣기는 직접 해요.
  - 복사가 막혀 있으면 총괄 창에 “사이트 전달 감시 다시 켜 줘”라고 보내요.
- 서버를 끄고 다시 켜도(업데이트 포함) 쌓여 있던 말은 이어서 전해요. 서버가 갑자기 꺼졌거나 5분 넘게 꺼져 있었으면, 또 0.7.0 전 판에서 처음 업데이트할 때는 그 대화에 ‘못 전했을 수 있어요’ 줄이 남아요. 뒤에 ‘총괄이 전했어요’ 줄이 없을 때만 다시 보내요.

### 메시지가 전해지는 길

```
브라우저나 맥 앱 창(127.0.0.1:8765)
   │  POST /api/say · /api/meeting/* · /api/decide   (Host·Origin·열쇠 확인)
   ▼
office_server.py ──► 팀 사무실 파일에 기록 (chat/*.jsonl, meetings/*, approvals/*, log.jsonl)
   │
   └─► outbox/<id>.json  (전달할 메시지, 서버가 만든 것만 등록)
            │
            ▼
총괄(코디네이터) Claude Code 세션 ── Bash 백그라운드로 bin/relay_watch.py --until-item 실행
            │   RELAY <파일>을 찍고 끝나면 깨어나 같은 명령을 다시 켜고
            ▼
      SendMessage(to=세션 id, 내용 그대로)  ──►  팀 세션
                                                   │ 답은 Write로 .out/<역할>.txt에 쓰고
                                                   ▼
                                         bin/say.sh <대화 파일> <역할> --file …
                                                   │
                                                   ▼
                                    대화 파일 → 브라우저가 몇 초마다 다시 읽어 보여 줌
```

- 전달 감시기(`bin/relay_watch.py`)는 서버가 `outbox/.port`에 적어 둔 포트를 스스로 찾아요.
- 팀 세션이 답하는 규칙은 [TEAM_RULES.md](TEAM_RULES.md)에 있어요.

### 왜 세션에 직접 넣지 않나요

- 외부 프로그램이 세션의 메시지 소켓에 사용자 입력처럼 글을 넣는 방식은 Claude Code의 자동 모드 안전장치가 막아요. 그래서 공식 도구인 `SendMessage`로만 전해요.
- 화면에서 온 말은 다른 세션을 거친 메시지라 **승인(커밋·배포·결제 등)으로 쓰이지 않아요.**

## 터미널로 층 만들기

설정 화면의 **사무실 만들기**가 가장 쉬워요. 터미널로 하려면 이렇게 해요.

```bash
python3 bin/new_team.py
```

물어보는 것:

- 팀 id, 프로젝트 폴더, 층 이름, 업무 번호 머리글
- 기본 네 자리(팀장·개발자·디자이너·기획)의 세션 id. 모르면 비워 둬도 돼요.
- 더 둘 역할과 그 세션 id. 쉼표로 적고(예: `마케팅, QA`), 없으면 엔터.
- 처음이면 예시 팀을 뺄지와 총괄 세션 id

한 번에 만드는 것:

- `<프로젝트>/.office/` 팀 사무실
- `teams/<id>` 연결
- `org.json`의 다음 층 (고치기 전 내용은 `org.json.bak`에 남겨요)

알아 두면 좋은 것:

- 다 물어본 뒤에야 파일을 만들어요. 중간에 멈추면 아무것도 바뀌지 않아요.
- 팀 사무실에는 `.gitignore`(`*`)를 둬서 팀 기록이 커밋되지 않게 해요.
- 끝나면 `@.office/RULES.md` 한 줄을 프로젝트의 `CLAUDE.local.md`에 넣어요. 그러면 그 프로젝트의 세션들이 팀 규칙을 읽어요.
- 세션 id(`local_…`)는 각 세션에서 "이 세션 id 알려 줘"라고 물으면 알려 줘요.
- 팀원은 나중에 설정 화면의 **팀원 고치기**로 바꿔요.
- 손으로 꾸리려면 `examples/teams/demo/` 구조와 [TEAM_RULES.md](TEAM_RULES.md)를 참고해요.

## 에이전시티 도시

등록한 사람마다 **토큰 작업량만큼 높은 건물**이 하나씩, 본인이 고른 **나라 구역**에 서요. 건물을 누르면 카드가 열리고, 주인이 공개한 층(팀)만 **읽기 전용**으로 둘러봐요. **숫자** 보기로 바꾸면 총 토큰 순위표가 나와요.

### 도시 열기

- 사무실 위쪽 **도시 보기 →**
- 또는 `http://127.0.0.1:8765/city.html` (예시 도시는 `city.html?demo=1`)
- 설치하지 않아도 [min-heee.github.io/agencity](https://min-heee.github.io/agencity/)에서 봐요. **도시 보기 →**와 같은 페이지인데, **← 내 사무실**이 없고 내 `org.json`의 도시 설정은 쓰지 않아요.
- `city.html`은 정적 파일이라 GitHub Pages 같은 곳에 그대로 올려도 돼요.

### 건물은 이렇게 서요

[도시 명단](https://github.com/Min-heee/token-meter)(`members.json`)과 각자의 공개 gist를 읽어요. 내 건물은 [4단계](#도시에-내-건물-세우기)에서 세워요.

| 도시에서 | 뜻 |
|---|---|
| 높이 | 작업량의 로그 눈금, 1~40층 |
| 창문 불빛 | 최근 7일 중 활동한 날 |
| 금빛 띠 | 공개한 층(팀) |
| 바닥 구역 | 본인이 고른 나라. 총 토큰 합이 큰 나라가 뒤쪽이고, 나라를 안 고른 사람은 맨 끝 ‘나라 안 고름’ 구역이에요 |

- 작업량 = 총 토큰 − 캐시 읽기 + 캐시 읽기 × 0.1
- 숫자는 각자 신고한 값이라 검증할 수 없어요. 도시에는 ‘자기 신고’라고 표시해요.
- 다른 명단을 쓰려면 `org.json`에 `"city": {"registry": "https://…/", "me": "<내 아이디>"}`를 넣어요. 명단 주소는 https여야 해요.

### 보기·나라·언어

위 막대에서 바꿔요. 주소에 적어 두면 그 모습으로 열려요(`city.html?view=numbers&country=KR&lang=en`).

- **[빌딩 | 숫자]**: 숫자 보기는 순위표예요. 순위는 **총 토큰** 기준이고, ‘오늘’ 칸 머리를 누르면 오늘 순으로 봐요. 같은 값이면 같은 순위예요.
  - ‘오늘’은 **그 사람 시간대의 오늘**이에요. 오늘 아직 숫자를 올리지 않았으면 `—`예요(0이 아니에요). 숫자는 올린 때까지만 맞아요.
  - 30일 넘게 숫자를 안 올린 줄은 흐려요. 내 줄은 ‘나’로 표시해요.
  - 건물 높이는 작업량(캐시 읽기는 10분의 1) 기준이라 순위와 다를 수 있어요.
- **[나라 ▾]**: 그 나라 구역으로 가까이 가고, 순위표는 그 나라 안에서 1위부터 다시 매겨요(작게 전체 순위). 휴대폰은 내 나라 구역부터 열어요(내 건물이 없거나 나라를 안 골랐으면 전체).
- **[한국어 | English]**: 화면 글, 나라 이름, 숫자 꼴(3.4억 / 340M), ‘3시간 전’ 같은 때 글이 바뀌어요. 사람이 쓴 글(소개·층 이름·업무판)은 번역하지 않아요. 처음엔 주소의 `?lang=` → 이 브라우저에 기억한 값 → 브라우저 언어 순이에요.
- 내 카드에는 **공유 글 복사**가 있어요(나라를 골랐으면 나라 안 순위, 아니면 전체 순위).

### 설치 없이 건물만 세우기

에이전시티를 깔지 않아도 돼요. 공개 도시의 **내 건물 세우기 →**에서 나라를 고르면(안 골라도 돼요) 명령 한 줄이 만들어져요.

```bash
curl -fsSL https://raw.githubusercontent.com/Min-heee/agencity/v0.9.2/bin/city_join.py | python3 -I - --country KR
```

1. 같은 판의 숫자 세기 도우미(`bin/token_meter.py`)와 나라 목록만 임시 폴더에 받아 쓰고 끝나면 지워요. 설치 폴더를 만들지 않아요.
2. 이 컴퓨터의 Claude Code·Codex·Gemini CLI 로그에서 토큰 수·모델 이름·시각만 세요(대화 글은 읽지 않아요).
3. GitHub에 로그인해요: gh에 로그인돼 있으면 그 계정, 아니면 기기 코드(권한은 gist 하나). 토큰은 파일로 남기지 않아요.
4. 올라갈 내용을 보여 주고 `올릴까요? [y/N]`을 물어요(`v`와 엔터면 올라갈 글 전부). 엔터만 누르면 아무것도 안 올라가요.
5. `y`를 치고 엔터를 누르면 내 공개 gist에 사용량 파일을 올리고, `--country`를 줬으면 같은 gist의 `agencity.json`에서 나라만 고쳐요(소개·층은 그대로). 아직 도시 명단에 없으면 **도시 참가 신청** 화면을 열어 줘요. 제출은 본인이 눌러요.

- 준비물은 맥이나 리눅스의 터미널(윈도는 WSL), python3, GitHub 계정이에요(node·gh는 없어도 돼요). 맥은 python3를 처음 쓸 때 명령어 도구 설치 창이 떠요. 설치가 끝나면 같은 줄을 다시 실행해요.
- 붙여 넣기 전에 스크립트를 읽어 볼 수 있어요: [bin/city_join.py (v0.9.2)](https://github.com/Min-heee/agencity/blob/v0.9.2/bin/city_join.py)
- 나라를 바꾸려면 `--country JP`, 빼려면 `--country none`으로 다시 실행해요. `--country`를 안 주면 나라는 그대로예요.
- 숫자를 새로 올리려면 같은 줄을 다시 실행해요. 숫자도 나라도 그대로면 아무것도 올리지 않아요. 저절로 올라가지는 않아요(자동으로 올리기는 에이전시티 앱에서 켜요).
- 저장소를 받았다면 `python3 bin/city_join.py --dry-run`으로 숫자만 세어 볼 수 있어요(로그인도, 올리기도 안 해요).
- 참가 신청 화면과 gist 파일 이름(`token-meter.json`)에는 도시 명단을 맡은 저장소 이름이 보여요.

### 내 층 공개하기

기본은 아무것도 공개하지 않아요.

**앱에서**: **설정 → 공개 범위**에서 고르고 **도시에 올리기**를 눌러요. 자세한 건 [4단계 공개 범위](#4단계-공개-범위)를 봐요.

**터미널에서**:

1. `public.example.json`을 `public.json`으로 복사해서 공개할 층만 적어요. 업무판 제목(`board`)과 책상의 지금 하는 일(`tasks`)은 따로 켜야 나가요. 둘 다 ‘둘러보기’(`tour`) 층에서만 나가요.
   - `gist`를 비워 두면 앱이 숫자를 올린 gist(`setup.json`), 없으면 내 gist 중 사용량 파일이 든 것을 찾아 써요.
   - 층 이름(`name`)을 적지 않으면 내부 팀 이름 대신 ‘n층’으로 나가요.
2. 미리보기로 나갈 내용을 확인해요. 경로·주소·메일·전화번호·키 모양 값·인용은 지우거나 그 줄을 빼요. 사람 이름은 자동으로 다 찾지 못하니 미리보기를 꼭 읽어 봐요.

   ```bash
   python3 bin/office_public.py
   ```

   파일로 남기려면 `python3 bin/office_public.py --write agencity.json`처럼 해요.

3. 괜찮으면 내 사용량 gist에 `agencity.json`으로 올려요. 올리기 전에 한 번 더 묻고, gist 주인·GitHub 로그인·`public.json`의 `login`이 같은지도 확인해요.

   ```bash
   python3 bin/office_public.py --publish
   ```

### 앞으로의 계획

사람마다 자기 사무실을 등록하면 토큰 사용량만큼 높은 빌딩이 서는 도시로 키워 가려고 해요. [Git City](https://github.com/srizzon/git-city)에서 영감을 받았어요.

- 건물의 층은 그 사람의 팀이에요.
- 기본은 비공개이고, 대화·결재·보고서 원문은 공개하지 않아요.
- 토큰 숫자는 내 컴퓨터에서 세고, 본인이 원할 때만 올려서 [도시 명단](https://github.com/Min-heee/token-meter)에 참가해요.

자세한 내용은 [VISION.md](VISION.md)에 있어요.

## 보안

### 접속

- 서버는 `127.0.0.1`에만 열려요.
- `Host`·`Origin`·페이지 열쇠가 맞고 JSON만 담은 요청만 처리해요. 페이지 열쇠는 서버를 켤 때마다 새로 만들어요.
- 다른 사이트가 이 페이지를 틀(iframe)에 넣지 못하게 `X-Frame-Options: DENY`, `frame-ancestors 'none'`을 보내요.

### 보여 주는 파일

- `index.html`, 도시 페이지(`city.html`, `examples/city/`), `org.json`, `hq/`, 등록된 팀 사무실 폴더 안으로 제한해요.
- 링크로 된 팀 사무실(`.office`)은 층으로 받지 않아요.
- 로그인 토큰이 있는 `~/.config/agencity/`는 어떤 경로로 와도 보여 주지 않아요.

### 읽는 정보

- GitHub 토큰(기기 코드 로그인)은 `~/.config/agencity/github-token.json`(0600)에만 둬요. 페이지나 응답, `setup.json`에는 넣지 않아요.
- Claude 세션 기록에서는 세션 id, 제목, 폴더, 마지막 활동만 읽어요.
- Codex 기록(`~/.codex`)에서는 세션 파일 첫 줄(`session_meta`)의 id와 폴더(`cwd`), `session_index.jsonl`의 제목(`thread_name`), 세션 파일을 고친 시각만 읽어요. 보관한 세션(`archived_sessions/`)은 빼고, `~/.codex`에는 아무것도 쓰지 않아요.
- 역할 낱말을 찾으려고 첫 메시지를 읽는 건 [추천 팀](#추천-팀)에서 대표가 **허락**했을 때만이에요.
  - Claude는 대화 기록(`~/.claude/projects/`)의 첫 사용자 메시지, Codex는 세션 파일의 첫 `user_message`예요. 앞의 600자만 봐요.
  - 이 맥 안에서 역할 낱말을 찾는 데만 써요. 저장하지 않고, AI나 인터넷으로 보내지 않고, 페이지·응답·기록·파일 어디에도 내지 않아요. 화면에는 맞은 낱말(낱말표의 것)과 어디서 찾았는지만 나와요.
  - Codex 세션 파일의 다른 줄(지시문, 환경 정보, 답, 도구 호출, 토큰 수)은 읽지 않아요.
  - **목록 정보만**을 고르면 첫 메시지는 읽지 않아요. 고른 것은 `setup.json`의 `readFirstMessages`예요.
- 세션 만들기·총괄 만들기로 기다리는 동안(30분까지)에는 허락과 상관없이 그사이 새로 만든 기록의 만든 시각과 대화 기록(`~/.claude/projects/`)의 첫 사용자 메시지에서 자리 표시만 찾아요. 그 내용은 페이지나 기록에 내지 않아요.
- Claude 앱 설정 파일에서는 사이드바 그룹(그룹 이름, 순서, 어느 세션이 어느 그룹인지)만 꺼내 써요. MCP 서버 설정 같은 다른 내용은 페이지나 기록에 내지 않아요.
- [도시에 내 건물 세우기](#도시에-내-건물-세우기)는 버튼을 누를 때(켜 두면 1시간마다 자동으로)만 `~/.claude/projects`, `~/.codex`, `~/.gemini`의 로그를 세요. 토큰 수·모델 이름·시각만 꺼내고, 대화 글은 꺼내지 않아요.
- [사용량 알림](#사용량-알림)은 켰을 때만 같은 로그에서 토큰 수·시각·응답과 세션 id·작업 폴더(층별로 나누려고)만 꺼내요. 이번 주(또는 5시간) 전에 고친 파일은 열지 않고, 그대로인 파일은 다시 읽지 않아요. 따로 띄운 도우미(`bin/usage_meter.py`)가 낮은 우선순위로 세고, 숫자는 이 맥의 화면에만 보여요. 아무것도 보내지 않고, 남기는 건 설치 폴더의 `.usage/cache.json`(0600) 하나예요. 끄면 읽지 않고(세는 중이면 멈추고) 그 파일도 지워요.

### 프로젝트 폴더에 쓰는 것

- 층을 만들면 층 폴더에 팀 사무실(`.office/`, 안에 `.gitignore`는 `*`)을 만들어요.
- [규칙 줄 넣기](#규칙-줄-넣기)는 층 폴더의 `CLAUDE.local.md`에 한 줄, git 저장소면 `.git/info/exclude`에 한 줄만 더해요. 링크인 파일은 고치지 않아요.
- [규칙 맞추기](#규칙-맞추기)는 팀 사무실 `RULES.md`의 에이전시티 표시 사이만 고치거나 맨 끝에 더해요. 표시 사이를 바꿀 때는 바꾸기 전 파일을 `RULES.md.bak`에 남겨요.

### 메시지 전달

- 서버가 만든 전달 항목만 총괄이 보내요. `/api/outbox/check`로 내용 해시를 확인해요.
- 감시기는 하나만 돌아요(`outbox/.watch.lock`). 총괄을 바꾸면 예전 총괄 id를 `outbox/.retired`에 적고, 쌓여 있던 항목은 새 이름으로 다시 내요. 그 뒤로는 지금 총괄의 감시기에만 항목을 확인해 주고, `--boss` 없이 켠 감시기는 바로 꺼져요.
- 서버를 끌 때는 아직 전하지 않은 항목의 id·해시만 설정 폴더의 0600 파일(`~/.config/agencity/outbox-….json`)로 넘겨요. 5분 안에 켠 다음 서버가 한 번 읽고 지워요. 그 파일에 없는 항목은 전하지 않아요.
- 1분에 30개, 대기 40개로 양을 제한해요.
- `bin/say.sh`는 정해진 대화 파일에만 써요. 보내는 사람은 역할 이름 모양(한글·영문·숫자 12자까지)이나 총괄만 되고, `대표`는 안 돼요.
- 화면에서 온 말은 승인이 아니에요. 위험한 일은 결재로 "하기로 정함"까지만 하고, 실제 실행은 그 세션 창에서 사람이 마지막으로 확인해요.
- `bin/tell.sh`는 `hq/teams.jsonl`에 기록만 하고 메시지는 보내지 않아요. 보내는 사람은 org.json·team.json에 있는 층의 팀장만 적을 수 있고, 글은 `hq/.out/`의 파일로만 받아요.
  세기와 덧붙이기는 잠금(`hq/.teams.lock`) 안에서 해요. **3번 더 하게 두기**(`/api/talk/allow`)는 왕복을 다 쓴 대화에 허락 줄 하나만 더해요.
- `claude://` 링크는 화면에서 대표가 누를 때만 열려요. 앱이 폴더를 묻고, 첫 메시지는 대표가 Enter를 눌러야 보내져요.
- Codex 자리에는 아무것도 전하지 않아요(읽기 전용).

### 새 버전 확인

- 하루 한 번까지 `https://github.com/Min-heee/agencity/releases/latest`에 요청 하나예요. User-Agent만 보내고, 끌 수 있어요.
- 업데이트는 화면에서 확인을 누른 뒤에만 해요. 그 태그의 `install.sh`를 HTTPS로 받아 실행하고, 다른 요청과 같은 Host·Origin·열쇠 검사를 거쳐요. **다시 켜기**도 같고, 받는 건 없어요.

### 도시에 올릴 때

- 내 건물(사용량 파일)에는 이것만 나가요: 도구별 토큰 수와 API 환산액, 응답·세션·서브에이전트 수, 날짜별 합계, 모델 이름(경로·메일 모양은 `(other)`), 시간대. 이름·프로젝트·경로·세션 id·대화는 나가지 않아요.
- 나라는 본인이 고른 것만 `agencity.json`의 `profile.country`(두 글자 코드)로 나가요. 시간대로 짐작하지 않아요. 도시에서 내리면 공개한 층과 함께 빠져요.
- **gist에 올리기**를 누를 때(켜 두면 1시간마다 자동으로 올리기, 숫자가 바뀌었을 때만)만 올려요. 올리기 전에 GitHub 로그인의 아이디가 올릴 문서의 아이디와 같은지 확인해요. 같은 gist의 다른 파일은 건드리지 않아요.
- [도시 명단](https://min-heee.github.io/token-meter/members.json)은 로그인 정보 없이 읽어요.
- 그만두려면 [탈퇴 이슈](https://github.com/Min-heee/token-meter/issues/new?template=leave.yml&title=leave)를 열고 gist를 지워요. 지우기 전까지는 지난 수정 기록도 공개로 남아요.
- 층 요약(`agencity.json`)을 만들 때 대화·결재·보고서·회의록·로그 파일은 어떤 경우에도 읽지 않아요.
- 책상의 지금 하는 일과 업무판 제목은 따로 켜야 나가요. 켜도 경로·주소·메일·전화번호·키 모양 값·인용은 지우거나 그 줄을 빼요.
- 사람 이름은 자동으로 다 찾을 수 없어요. 켜기 전에 미리보기를 꼭 읽어 봐요.

### 남는 위험

- 같은 맥의 다른 프로그램(에이전트 포함)은 페이지를 받아 열쇠를 읽을 수 있어요. 그래서 화면에서 온 메시지를 승인으로 쓰지 않는 규칙이 중요해요.
- `python3 build.py --snapshot`으로 만든 `artifact.html`에는 팀 데이터가 그대로 들어가요. 공개하기 전에 꼭 확인해요.

- 화면 글은 한국어예요.

## 설정 값과 파일

### 설치할 때 쓰는 값

`sh` 바로 앞에 `이름=값`을 넣어요.

```bash
curl -fsSL https://raw.githubusercontent.com/Min-heee/agencity/main/install.sh | AGENCITY_NO_APP=1 sh
```

| 이름=값 | 하는 일 |
|---|---|
| `AGENCITY_DIR=<폴더>` | 설치 위치를 바꿔요. 기본은 `~/agencity` |
| `AGENCITY_REF=<태그나 브랜치>` | 받을 버전을 골라요. 기본은 최신 릴리스 (예: `v0.4.0`, `main`) |
| `AGENCITY_NO_APP=1` | 맥 앱을 만들지 않고 브라우저로 켜요 |
| `AGENCITY_APP_DEST=<폴더>` | 앱을 `~/Applications` 대신 그 폴더에 만들어요. `make_mac_app.sh`도 같은 값을 써요 |
| `AGENCITY_NO_START=1` | 설치만 하고 켜지 않아요. 맥 앱도 만들지 않고 만드는 명령만 알려 줘요 |
| `AGENCITY_FORCE=1` | git으로 받은 폴더라도 덮어써요. 보통은 `git pull`을 써요 |

예전 이름의 `CLAUDE_OFFICE_DIR`·`CLAUDE_OFFICE_REF`도 설치 스크립트가 아직 받아 줘요.

### 켤 때 쓰는 값

| 이름=값 | 하는 일 |
|---|---|
| `OFFICE_PORT=<포트>` | `python3 start.py`를 다른 포트로 켜요. 기본은 8765 |
| `AGENCITY_GITHUB_CLIENT_ID=<Client ID>` | 기기 코드 로그인을 시험할 때 `github_client_id` 파일 대신 써요 |

그 밖의 `AGENCITY_…` 이름은 앱 안에서 쓰거나 시험할 때만 써요.

### 내 정보가 담긴 파일

다시 설치하거나 업데이트해도 아래는 그대로 둬요.

| 파일·폴더 | 내용 |
|---|---|
| `org.json`, `teams/` | 층 목록, 총괄, 팀 사무실 연결 |
| `hq/` | 총괄과의 대화 |
| `outbox/` | 전달할 메시지 |
| `setup.json` | 처음 설정 (GitHub 아이디·공개 범위·새 버전 알림·첫 메시지 읽기 허락·사용량 gist와 자동으로 올리기·사용량 알림과 한도, 토큰은 없어요) |
| `public.json`, `agencity.json` | 도시 공개 설정(고른 나라 포함)과 파일로 내보낸 요약 (예전 이름 때의 `claude-office.json`도 그대로 둬요) |
| `.update/` | 앱 안 업데이트의 진행 상태와 기록 |
| `.usage/` | 사용량 알림이 센 기록(로그 파일 경로와 크기·시각, 기간 안 기록의 토큰 수·시각·응답과 세션 id·작업 폴더, 0600, 켰을 때만) |
| `<프로젝트>/.office/` | 팀 사무실 (대화·상태·업무판·회의·결재·보고서) |
| `~/.config/agencity/github-token.json` | GitHub 로그인 토큰 (0600) |

- 예전 한 줄 설치로 받은 `~/claude-office`가 있으면 같은 한 줄을 다시 실행해요. 그 폴더를 그 자리에서 새 버전으로 바꾸고, 팀 정보도 그대로 둬요. `~/agencity`가 아직 없고 git 폴더가 아닐 때 그래요.
- 예전 이름의 설치 값도 설치 스크립트가 아직 받아 줘요.
- 도시는 예전 판이 올린 `claude-office.json`도 읽어요. 새 판으로 다시 올리면 그 파일은 지워요.
- 예전 더블클릭 파일은 설치할 때 지워요.
- 앱을 만드는 폴더에 예전 이름의 맥 앱이 있으면, 우리가 만든 앱일 때만 끄고 지워요.

## 관리자 메모: GitHub 기기 코드 로그인

이 저장소의 `github_client_id`에는 이미 Client ID가 들어 있어요. 직접 고쳐 배포하는 판에서만 아래가 필요해요.

설치 폴더의 `github_client_id`가 비어 있으면 **GitHub로 로그인**(기기 코드)은 꺼져 있고 gh 로그인만 보여요.

켜려면:

1. GitHub의 **Settings → Developer settings → OAuth Apps**에서 앱을 하나 만들어요.
2. **Enable Device Flow**를 켜요.
3. 그 **Client ID**를 `github_client_id` 파일 첫 줄에 넣어 함께 배포해요.

- Client ID는 공개해도 되는 값이고, client secret은 필요 없어요.
- 시험할 때는 파일 대신 `AGENCITY_GITHUB_CLIENT_ID` 환경 변수로 넣을 수도 있어요.
